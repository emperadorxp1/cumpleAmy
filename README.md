# Invitación · Amy cumple 4 🌺

Invitación web (Astro) con temática de océano/isla.

## Editar datos
Todo está en `src/config.ts`: nombre, fecha/hora, lugar, link de Maps, número de WhatsApp y lista de invitados.

## Fotos
- Foto de Amy: guárdala como `public/amy.jpg` (cuadrada) y pon `tieneFoto: true` en `src/config.ts`.

## Comandos
- `npm run dev` → http://localhost:4321
- `npm run build` → genera `dist/` (sube esa carpeta a Netlify, Vercel o GitHub Pages)
